# 🎙️ AI Voice Translator

An AI-powered voice and language translation project designed to help users communicate across different languages. The repository includes multilingual translation and word cloud-related components.

## 🚀 Project Overview

The **AI Voice Translator** project explores how speech processing, language translation, and text visualization can make multilingual communication easier and more accessible.

It includes two main components:

- **Multiple Language Translation** — focused on translating text between different languages.
- **Translator with WordCloud** — combines translation-related functionality with word cloud visualization.

## ✨ Features

- 🌍 Multilingual translation support
- 🎙️ Voice-based translation workflow, where implemented
- 📝 Text processing and translation
- ☁️ Word cloud visualization
- 💻 Python-based project structure
- 🔧 Modular components for exploring language translation applications

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/dhilleswar07/AI_Voice_Translator.git
```

### 2. Navigate to the project directory

```bash
cd AI_Voice_Translator
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

### 4. Install dependencies

If a `requirements.txt` file is available in the relevant project folder, install the dependencies using:

```bash
pip install -r requirements.txt
```

Otherwise, install the packages required by the imports in the Python files.

### 5. Run the application

Open the relevant project folder, identify its main Python file, and execute it:

```bash
python filename.py
```

Replace `filename.py` with the actual entry-point filename.
